# nibbles-legal

Static Support, Privacy Policy, Terms of Use and Medical & Safety Disclaimer pages for the Nibbles app, served by GitHub Pages at https://legal.thenibblesapp.com.

`privacy/`, `terms/` and `disclaimer/` are generated from `lib/src/features/legal/constants/` in the Nibbles app repo. Edit the app text, regenerate, and commit the output here so the app and the web pages never drift.
